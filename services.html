Questions people ask

How long does a project take?

A focused API or internal tool usually takes 2 to 6 weeks. ERP modules depend on the number of screens and integrations, so I give a timeline after the first call.

How do you price the work?

A fixed price per project once the scope is agreed. For ongoing work, a monthly block of hours. I ask for 40% upfront, with the rest tied to milestones.

Can you work with an existing codebase?

Yes. I read the code and the database first, then write down what I would change before changing it. If the code is not something I can work with safely, I will say so.

Who owns the code and the accounts?

You do. Repositories, domains, and deployment accounts stay in your name, and I work with your accounts where possible.

Are you available full time?

No. I work alongside a full-time engineering role, so I take one freelance project at a time and plan the timeline around it.

What do you need to start?

A short description of the workflow, access to any existing code, and one person who can approve the scope. A call is usually enough to decide whether we should work together.
