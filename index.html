About

I write backend systems in Python, and I like the part where a design has to survive real data and the next feature. Most of my work ends up as APIs and services, with web, desktop, or mobile clients on top.

ERP takes up most of my time. I have learned a lot by taking apart how established systems model inventory, accounting, and permissions, and I reuse those patterns when I design new modules.

Outside product work I stay close to the fundamentals: graph algorithms, build tooling, and network security.

RIPPLE

An incremental build analysis engine in C++

Works out which files need rebuilding after an edit, and in what order, without calling the compiler. It combines an include graph, content hashing, and Kahn’s algorithm, and reports dependency cycles instead of failing silently.

  • C++
  • Graph algorithms
$ ripple --changed src/main.cpp
[ok]   hash    a41f9c…2b7e
[ok]   graph   4 dependents found
[ok]   order   main → utils → engine → cli
[warn] cycles  none
4 files queued for rebuild

SentinelNet

A detection tool for campus Wi-Fi

Detects ARP spoofing, deauthentication floods, and Evil Twin access points, and seals the evidence with SHA-256 fingerprints. Each detector has an alert test and a benign test.

  • Scapy
